# Verification: foundations

How to run this file: most items are observable through a scratch-folder scan (`/tmp/dedupe-verify`-style fixture) and the web UI over it. Keep the hash cache between items unless the item says to clear it (`rm ~/.cache/dedupe/hashes.sqlite3`). Device column values: `cli` = terminal run of `.venv/bin/dedupe`; `ui` = browser at `http://127.0.0.1:8765`; `disk` = inspect files on disk.
